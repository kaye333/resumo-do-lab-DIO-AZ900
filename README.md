# resumo-do-lab-DIO-AZ900
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO AZ-900

## LAB1 - Localizando Serviços por Categoria

Menu: Configurações:
- Demonstrado como trocar o idioma do portal Azure.
- Demonstrado como é feito a alteração visual/gráfica do portal.
- Demonstrado como esconder/mostrar o menu lateral.

Barra lateral: Todos os Serviços:
- Demonstrado como encontrar os serviços disponíveis no portal Azure separados por categorias.
- Reforçado o conceito de VERSÃO PRÉVIA, sendo um serviço que ainda está sendo implantado no portal e não possui garantia (SLA), podendo ser retirado do portal Azure.
